# UTS_Pemrograman2_25183207038_SendyTriAdmaja

Nama : Sendy Tri Admaja
NPM : 25183207038

Deskripsi Singkat : 
Aplikasi console berbasis Java untuk mengelola penyewaan kendaraan (mobil dan motor). Aplikasi menerapkan konsep OOP: class & object, encapsulation (private + getter/setter), constructor, inheritance (Mobil dan Motor mewarisi Kendaraan), serta method override pada tampilkanInfo(). Data disimpan sementara di ArrayList<Kendaraan>.Struktur file: Kendaraan.java, Mobil.java, Motor.java, Main.java.
